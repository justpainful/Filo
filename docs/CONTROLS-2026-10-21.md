# Float, Acrylic controls and glass close buttons — 0.1.5

## Float fixes

Expanding, collapsing or removing a reference previously resized the HWND from inside its Direct2D draw. DXGI could not resize the swap chain while the frame still held its back buffer; the render target was released, leaving Float unable to repaint its controls. Shelf state changes now run as posted commands after the frame. The shelf closes after removing its last reference.

The compact shelf has a permanently visible close button. The expanded panel is 280 DIP wide, with independent, always-visible remove controls, a collapse button and a Clear shelf footer. Close/remove controls claim input before the surrounding drag targets. The footer claims input before partially clipped list rows, so long lists cannot swallow Clear shelf clicks. Removal commands use stable item IDs rather than mutable row indexes. Clearing or closing removes references only; original files are not deleted or rewritten.

OLE drag startup and return explicitly release pointer capture and reset the UI's pressed state. WM_CAPTURECHANGED/WM_CANCELMODE also cancel stale input, and released captures cannot remain owned by disappearing widgets. Mouse-down reads current modifier flags for multi-selection. Selected references can be removed with Delete; Escape closes the shelf. Busy drag state defers window disposal until the shell drag returns.

## Acrylic controls

Settings → Appearance puts Glass above the icon packs. Acrylic has two independent controls:

- **Transparency**, 0–100% (default 85%): changes material coating opacity, leaving text/icons opaque.
- **Background blur**, 0–48 logical pixels (default 30): changes the native Gaussian effect independently of transparency.

Both settings persist in `acrylicTransparency` and `acrylicBlur`, with validated ranges and defaults for old settings. The old Glass intensity remains available for Liquid/Soft; it does not silently limit the new Acrylic transparency control. Reduce transparency/high contrast still disable native transparency.

The dark recipe preserves tonal variation instead of clipping broad neutral areas to a flat brightness: live RGB is toned by 0.24 with a small lift and a safe upper bound. Light mode retains its luminosity floor. This keeps colour/detail changes visible when adjusting blur while preserving reading contrast. The Windows host brush can already contain system frost; the blur control sets Filo's additional Gaussian pass. No desktop screenshots or image refresh timer are used in the runtime.

## Close button

Every Filo window uses the same 28 DIP circular glass close control at top left, including RTL layouts (0.1.6): tool windows, Settings, the widget gallery, Float and the progress card (`DialogOptions::glassCloseButton` now defaults to true, so a new window gets it without extra code). In the progress card the button cancels a running conversion. The control has an independently clipped, compositor-owned live host-backdrop circle with 8 DIP additional blur. Its UI foreground is cleared only inside that circle, then a translucent coating, radial inner depth, directional white rim, quiet shadow and thin rounded × are painted above it. Thus the local blur is a live material rather than a simulated flat fill or a blurred glyph.

Hover eases to 1.03 scale; press eases to 0.97 and mutes reflection. Disabled controls reduce rim/ink contrast and ignore clicks. Reduce motion disables size animation. Unsupported host composition and reduced transparency use an opaque styled fallback. The × uses the specified dark grey on light surfaces and near-white on dark surfaces, independently of icon pack choice.
